# 🍽️ QuickOrder

Realtime QR Restaurant Ordering System

QuickOrder is a modern restaurant ordering platform that allows customers to scan a QR code, browse the menu, place orders, and track their order status in real time.

The project includes:

* 📱 Customer mobile ordering interface
* 🍳 Kitchen management dashboard
* ⚡ Realtime order updates with Socket.IO
* 📦 Live order tracking system
* 🧾 Category-based digital menu
* 🔔 Order ready notifications
* 📊 Agile sprint workflow & Git branch management
